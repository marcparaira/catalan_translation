# EU4 translation: points for manual review

All of `EU4_l_english.yml` (5,047 entries) is translated and merged into [ca_EU4_l_english.yml](../localisation/replace/ca_EU4_l_english.yml). Each row below is a choice the translators were unsure about. **The Catalan shown is what the file contains now**, so nothing here is blocking. Write your decision in the last column (or just tell me) and I'll apply it, and add the agreed terms to the glossary.

## 1. Project-wide decisions (these affect future files too)

1. **Possessive/pronoun scopes (`GetHerHis`, `GetHerHim`, `GetSheHe`, keys `EV_HIS`/`EV_HER`/`EV_HIM`/`EV_SHE`…).** Catalan possessives agree with the thing owned, not the owner, so no single value works. EU4 now assumes `GetHerHis` = «seu» used as «el [GetHerHis] + masc. noun», and `GetHerHim`/`GetSheHe` = «ell/ella». `ca_powers_and_ideas` already uses `[GetHerHis]` without an article before feminine/plural nouns, so the two files disagree. Options: (a) rewrite sentences to avoid these scopes where the validator allows, (b) add Catalan helpers (`GetCaSeuSeva`…) in `customizable_localization`.
2. **Ruler/heir/consort gender** (`Monarch.GetTitle`, `$CONSORT$`, «nou hereu»). The text avoids gendered articles and adjectives («el càrrec de [Title]», «Visca [Title]!» with no article). A gender-aware helper would read more naturally.
3. **Names inside `$VARIABLES$`.** Translators used three patterns to avoid «de Anglaterra» / «a Japó»: a colon (`Independència: $COUNTRY$`), parentheses (`Fanàtics ($RELIGION$)`) and «del país $COUNTRY$». A few places still have «de/a $VAR$» (`FLEET_BASING_RIGHT`, `HAVE_MORE_THAN_CAVALRY_IN`, `PAPAL_GRANTED`, `IS_SUBJECT_OF`, which the engine completes itself). Confirm the patterns are acceptable.
4. **Religion and culture names.** Religions mix adjectives (*catòlica*) and nouns (*xintoisme*), so rebel names use parentheses. Culture names were translated as lowercase **feminine** adjectives (*iroquesa*, *algonquina central*), agreeing with «cultura». A convention is needed before the cultures/religion files are done.
5. **`$ADJ$` is the masculine adjective.** Feminine nouns were reworded («El poder naval $ADJ$», «Xarxa d'espionatge ($ADJ$)»). `PARL_TITLE_TEXT` («$NAME$ $ADJ$») still gives «Assemblea Nacional francès».
6. **War names with `$ORDER$`** («$ORDER$$FIRST$ Guerra per…»): the ordinal comes from another key and must be feminine to agree with *guerra*.
7. **Event options:** imperative options were written as infinitives («Cremar el sacerdot!»), following the button rule; exclamations stay as speech. Confirm this applies to event options.
8. **DLC names** were kept in English (the official Spanish translates them). Hindu ruler titles (Raja, Rani, Maharaja…) and native parliament names (Sejm, Duma, Meclis…) were kept as is.

## 3. Changes I made for consistency after the chunks were merged

The file was translated in 8 parallel chunks. Where they disagreed I made them consistent:

- *membre menor/principal* → **soci menor/principal** (personal union), 7 entries.
- *Exèrcit ($RELIGION$)* → **Exèrcit fanàtic ($RELIGION$)**, 5 entries (shinto, animism, shamanism, mwari, totemism).
- *amplada de combat naval* → **amplada d'enfrontament naval** (2 tooltips); `ab_more_ships_can_fire` *Combat naval* → **Enfrontament naval**.
- `COLONY_PROGRESS` *colons* → **pobladors**.
- *Lollards* → **lol·lards** (9 entries; had been left in English).
